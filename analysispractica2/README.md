# Pràctica 2: Tractament del dataset de pisos en lloguer a Barcelona

## Autors
- Alexander Morales Fajarnés
- Esteve Creus Culell

## Descripció
Tractament i anàlisi del dataset de pisos en lloguer a Barcelona generat a la Pràctica 1.
S'apliquen tècniques de neteja, transformació i anàlisi de dades per respondre a la pregunta:
quins factors influeixen més en el preu del lloguer a Barcelona?

## Fitxers

### Codi
- `analysis/practica2_pisos_barcelona.Rmd` ---- codi R amb tota la neteja i anàlisi

### Dataset
- `dataset/pisos_barcelona_v2.csv` ----  dataset original amb algunes correccions per agafar totes les dades extret de pisos.com
- `dataset/pisos_barcelona_final.csv` ----  dataset net després del procés de neteja

## Requeriments
R amb els paquets: `tidyverse`, `corrplot`, `randomForest`
